# Tyholt Pizzeria

Et pop-up pizzeria i Trondheim. Første gang var i festningshelga 4.–5.
september 2026: to kvelder, tre pizzaer til 59 kr stykket og over 300 solgt.

Nå tar vi catering til bursdager, firmafester og andre arrangementer.

**[tyholtpizzeria.com](https://tyholtpizzeria.com)** – meny, helga i tall og
kontakt.

Bestillingssystemet lagde vi selv. Det ligger i dette repoet, og
[UTVIKLING.md](UTVIKLING.md) forklarer hvordan det henger sammen og hvordan
det kjøres.
